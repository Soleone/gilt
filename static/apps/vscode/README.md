# Gilt for VS Code

A dark theme of cool obsidian, warm parchment, sovereign gold, and restrained jewel tones.

Copper keywords, ivory functions, lapis variables, gold types, and jade for strings and numbers.
Comments in muted taupe, selection in gold shadow.

Part of [Gilt](https://github.com/Soleone/omarchy-gilt-theme): one palette for Omarchy, terminals,
editors and more. This theme is generated from that palette, so edit `colors.toml` and `roles.toml`
in the main repo rather than these files.

## Install

Build and install the package:

```bash
npx @vscode/vsce package
code --install-extension gilt-theme-0.1.0.vsix
```

Then pick **Gilt** with `Preferences: Color Theme`.
